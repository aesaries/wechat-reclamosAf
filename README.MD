# Chatboot Reclamos

Sistema de gestión de reclamos vía WhatsApp con derivación a webchat.

## Estructura del proyecto

- `bot/` — Bot de WhatsApp (Baileys)
- `backend/` — API y lógica del servidor (Node.js + Express)
- `frontend/` — Webchat y panel de administración
- `database/` — Base de datos SQLite
